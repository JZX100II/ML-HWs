# Machine Learning Coursework

This repository contains four homework assignments covering supervised learning, unsupervised learning, dimensionality reduction, and model evaluation.

## Contents

- **HW1: Linear Regression:** Implemented gradient descent and the normal equation, comparing the resulting parameters and regression performance using MSE, RMSE, normalized error, and \(R^2\).

- **HW2: Logistic Regression:** Developed a binary classification pipeline for COVID-related data, including preprocessing numerical and categorical features, addressing class imbalance, evaluating classification performance, and analyzing feature correlations.

- **HW3: K-Nearest Neighbors and Support Vector Machines:** Implemented KNN from scratch and compared its predictions with scikit-learn. Evaluated different distance metrics and neighborhood sizes, and compared SVM kernels on classification and nonlinear synthetic datasets.

- **HW4: PCA and K-Means:** Implemented Principal Component Analysis (PCA) and K-Means from scratch. Compared PCA results with scikit-learn, explored image compression using different numbers of components, and investigated clustering on the Iris dataset using different cluster counts and the elbow method.

## Technologies

Python, NumPy, pandas, Matplotlib, scikit-learn
